# 💻 C Programming Projects

A repository dedicated to my hands-on C programming projects. This collection serves as a practical playground for exploring C fundamentals, including control structures, user input handling, randomized logic, and basic algorithms.

## 🚀 Projects Included

Here is what is currently available in this repository:

*   **🧮 Calculator:** A command-line calculator that performs basic arithmetic operations (addition, subtraction, multiplication, and division) based on user input.
*   **🔢 Number Guessing Game:** An interactive game where the computer selects a random number, and the user must guess it with hints provided for "too high" or "too low."
*   **🔑 Password Generator:** A utility tool that generates secure, randomized passwords of customizable lengths using a mix of characters, numbers, and symbols.
*   **🐍💧🔫 Snake Water Gun Game:** A terminal-based recreation of the classic "Rock Paper Scissors" style game where the user plays against randomized computer choices.

## 🛠️ How to Compile and Run

To run any of these projects on your local machine, you will need a C compiler (like GCC) installed.

1.  Clone this repository to your local machine:
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    ```
2.  Navigate to the directory of the project you want to run.
3.  Compile the `.c` file using GCC:
    ```bash
    gcc filename.c -o outputname
    ```
4.  Execute the compiled program:
    *   On Windows: `.\outputname.exe`
    *   On Linux/macOS: `./outputname`
